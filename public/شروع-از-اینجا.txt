این سایت همین حالا کار می‌کند، اما در «حالت نمایشی» است:
داده‌ها فقط در مرورگر هر بازدیدکننده ذخیره می‌شوند و رمزها عمومی‌اند.

برای تبدیل به نسخه واقعی و امن، فقط یک فایل را ویرایش کنید:

  ┌──────────────────────────────────────────────────────┐
  │  فایل:  config.js   (همین‌جا، کنار index.html)        │
  └──────────────────────────────────────────────────────┘

۱) در supabase.com یک پروژه بسازید (رایگان).
۲) به Settings ← API بروید و دو مقدار را بردارید:
      Project URL          →  https://xxxxxxxx.supabase.co
      anon / public key    →  eyJhbGciOi...
۳) فایل config.js را باز کنید و دو خط را جایگزین کنید.
۴) همان فایل را ذخیره و دوباره آپلود کنید. تمام.

  ⚠ کلید service_role را هرگز اینجا نگذارید.

بعد از این کار، نوار قرمز «حالت نمایشی» از بالای صفحه محو می‌شود.

قبل از استفاده واقعی، دو کار دیگر هم لازم است (یک‌بار):
  • فایل supabase/schema.sql را در SQL Editor سوپابیس اجرا کنید
  • سه کاربر مدیریتی را در Authentication ← Users بسازید
